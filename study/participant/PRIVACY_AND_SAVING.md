# Your answers stay under your control

No account, analytics, automatic upload, cloud storage, localStorage or recording is added by these standalone forms. Only browser memory and files you choose to save contain your responses. Closing the tab loses unsaved entries. External source/app links are optional user-initiated navigation and use those sites' hosting/privacy policies.

Save My Responses: Downloads a file containing your answers to this device. Nothing is sent automatically. Your answers are saved as a .json file so the study organizer can review them. You do not need to open or edit it. Save a readable copy creates .txt instead.

Blank and partial files are supported. The page distinguishes entries, file generation and browser download request; it cannot confirm a browser completed a download. Check Downloads, retry or use the text alternative. A detectable generation error keeps your entries in this tab. No success message claims organizer receipt.

Use an organizer-assigned anonymous code, never your name. Do not enter private records, contact details, credentials or identifiers. Common patterns are blocked, but no detector can guarantee removal of every private fact. Share a file only voluntarily under your organizer's disclosed consent/retention arrangements. A withdrawal file does not authorize organizer use. Ask how to withdraw before aggregation and how long records are retained; no institutional approval is asserted by this kit.

Page clocks/answer counts do not establish genuine participation, correct answers, valid consent or a formal timed session. A facilitator must verify those separately. Activity order and protocol version are included so incompatible versions need not be pooled.
