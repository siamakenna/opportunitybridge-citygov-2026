# Optional five-minute first impression — separate protocol

Protocol opportunitybridge-first-impression-1.0. This is not the paired 15-minute study; do not pool it with formal task scores/times. Adults 18+, voluntary, no personal records. Confirm consent with the organizer; stop at any time without affecting services. No outreach has been sent.

Suggested cap: one minute orientation, three minutes exploring, one minute feedback. Open https://siamakenna.github.io/opportunitybridge-citygov-2026/ . In brief notes or aloud: identify an interesting opportunity; locate one key requirement; explain the fictional-practice disclaimer; identify a next step; name one confusing aspect. Missing/unfinished answers are valid observations. No need to finish a quest or download a Passport.

Organizer records actual starts/stops, assistance, unavailable sources and access barriers if a real consenting person participates. Never infer participation from a timer. Keep respondent identity outside public materials. No result cells are populated here. A casual comment remains qualitative feedback, not a formal timed session.
