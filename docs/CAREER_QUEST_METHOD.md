# Career Quest v0.8 — methods, coverage and limits

The three playable quests are the product centerpiece. Discovery and small learning-progress tokens support their artifacts; real sources and conventional preparation remain accessible without playing. No account, persistence, ranking, streak loss, random reward, artificial countdown or employment match score. Independent consenting unfamiliar participants: **n=0**.

## Release-blocking taxonomy

The v0.7 substring expression admitted INTERNAL titles through `intern` and unrelated professional titles through `graduate`. v0.8 replaces it with a structured taxonomy and per-category provenance: publisher-stated, source-reviewed, inferred candidate, or unknown. Title tokens have word boundaries and context; graduate alone never establishes entry level, and contractual alone never establishes a short engagement. Explicit internship wording in a publisher title establishes only that title's metadata, not pay or eligibility. Reviewed MPT Student Fellow records retain fellowship and part-time types, each with source provenance.

Both publication workflows run `npm run test:classification` as an explicit release blocker, as well as the complete suite. Negative cases include INTERNAL AUDITOR II, INTERNAL INVESTIGATION DETECTIVE SERGEANT, GRADUATE PROFESSIONAL ENGINEER and CONTRACTUAL ACCOUNTANT. Publisher MPT Spring Internship retains unknown pay and no approved qualification mapping. Existing approved catalog mappings and their dates are unchanged.

Supported contract types: full-time, part-time, paid/unpaid/pay-unknown internship, fellowship, research, apprenticeship, short contract, micro-project, course/training, service, competition, scholarship and career resource. A supported schema value does not imply connected supply. Most RSS employment types remain unknown because this feed does not expose enough arrangement metadata. All records retain classification basis, source routes, dates, pay/cost, duration, arrangement and stage values or explicit unknowns. No numeric confidence probability is used.

Category chips combine with OR; query and detailed filters combine with AND. Search is accent-, punctuation- and case-normalized over visible titles/employers/providers/location/skills/sector, with no fuzzy occupational matches. Unknowns are included by default and may be filtered deliberately. Short-duration filtering requires actual numeric duration metadata; an unknown is not treated as a short activity. Interest choices only reorder current results and are never stored. Reset all filters restores initial order; Reset whole session also clears all learner drafts, saved records, quest answers and completion records.

## Three actual exercises

1. **Source Detective**, estimated 3–5 minutes: the frozen Administrative Specialist I case requires 30 credits, six administrative months, an official-source evidence choice, an insufficient-information applicant conclusion and rejection of a hiring guarantee. Five checks must pass. A correct source-learning note may transfer into Passport. Always labeled a frozen historical learning case, irrespective of current availability.
2. **Build an Accessibility Artifact**, estimated 5–8 minutes: five predefined choices repair a fictional library preview's map text, text palette, heading structure, link label and associated form label. The actual preview changes and a repaired, self-contained HTML demo and JSON decision log can be downloaded. Only those five objective conditions are scored. The initial example intentionally demonstrates inaccessible content; it is not a real public-service form, accepts no personal email and submits nothing. Completion is not WCAG certification.
3. **Career Evidence Builder**, estimated 5–10 minutes: a fictional experience, an allowed skill, a valid reviewed MPT task/condition, a specific proposed artifact and a human question must actually be supplied. Empty steps, invalid source associations and selected unsupported hiring/eligibility phrases cannot complete it. This is limited deterministic checking, not universal claim verification. Successful transfer opens all five editable Passport fields and retains the quest/source receipt.

Every quest offers feedback, explanations, reset/retry, a local artifact and a Passport route. Learners can play in any order. Passport retains guided stages plus Show all five fields, previous/next controls, a fictional sample, connection reset, full worksheet reset, live text preview and explicit missing-field feedback. A completed plan still requires human review. Historical exercises remain separate proposed connections with original attribution and unknown career outcomes.

## Progress ledger

One completion per quest ID/version per in-memory session. Source Detective awards 30 learning XP; accessibility and evidence planning award 40 each. Maximum 110. All essential checks and an allowed frozen source identity are required; an asserted passed flag with a failed check or foreign source cannot award progress. Replays award no duplicate XP. Completion stores quest ID/version, actual checks, source snapshot, actual timestamp and optional notes; a local progress download makes the ledger inspectable. Evidence Explorer, Skill Builder and Evidence Planner describe these in-app actions only. Full reset or reload clears them. No third party recognizes these as credentials. Plain learning view hides XP and decoration and preserves every activity.

## Source coverage

Maryland's advertised public RSS remains the only connected discovery feed. Twelve curated reviewed/pathway/history records remain distinct. Three individually checked learning resources and three directory routes supplement them. At least five individual types occur across the reviewed set (full-time, part-time, fellowship, paid internship, research and course); directory-only service/apprenticeship/micro-project discovery is not represented as individual openings. The target of a publicly verified individual short paid project was not met: the correct product behavior is an empty state with an explicitly outbound Parker Dewey directory.

All new supplemental metadata is a source-backed AI-assisted review, not independent adjudication. Curated resource dates become recheck labels after 48 hours; RSS refresh never renews them. NIH/DOE intakes preserve their own source reviews and holds. USAJOBS API remains disabled pending owner-controlled credentials. No private LinkedIn/Handshake scraping or new paid integration.

## Reproducibility and performance protocol

`tests/v08-trial.html` is a runnable public harness. It runs the same 16-task protocol, expanded into 24 checks, twice in fresh iframe documents. There is no app storage; profiles and cache are shared, rather than pretending these are independently isolated browser profiles. Each run restores app state, uses the versioned data/trial-v08.json fixture and fixes discovery time at 2026-10-27T02:00:00Z. Frozen mode is visibly labeled and never used for normal discovery. Quests always score their frozen learning case.

Reports retain release SHA, frozen snapshot SHA-256, filtered IDs/order, exact task statuses, actual JSON and Markdown generation checks, progress decisions, source identities/dates/hashes and unknowns. Comparison removes only generatedAt, completedAt and personal due timestamps recursively. No binary-identity claim is made for intentionally dynamic dates. Download buttons retain both trial Passports and the full report for actual file inspection.

Measurements use browser Navigation/Resource Timing, buffered initial layout shifts when supported, and performance.now around synchronous DOM interactions. DOM timings exclude subsequent paint and human thought. Encoded resource bytes and actual transferred bytes are reported separately; cache reuse is visible. Browser version, viewport, unthrottled network and sample count are retained. Local and public timings are synthetic observations, not real-user speed or career improvements. Initial CLI/test failures, regressions and missing independent adjudication remain in the execution report.
