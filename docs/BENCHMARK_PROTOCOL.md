# Benchmark protocol · v0.4 · frozen October 26, 2026

Primary software benchmark: eight tasks in evidence/real-benchmark-cases.json, with exact official-source links and frozen evaluation time. Covers the Maryland college-credit route, partial accounting-credit substitution, required/preferred distinction, official NIH application destination, expired Coding it Forward intake, honest handoff, NIH institutional deliverable and self-reported historical offer. `npm run benchmark` writes actual 8/8 internal task checks to evidence/real-benchmark-results.json and creates evidence/real-manual-worksheet.md. The retained practice benchmark separately passes 12/12 judgments. Neither is a human comparison or a hiring result.

## Equal-information human comparison

Both conditions get identical fictional declarations, task text, frozen approved source packets/URLs and blank response fields. Manual condition may use normal browser find, notes and the source worksheet. Assisted condition may use OpportunityBridge but gets no additional evidence. Both may open the same official pages; count extra discovery steps rather than hiding them. No access to gold answers during the task. The source HTTP hashes document retrieval where it succeeded, not a substitute for complete source review.

Before recruitment, an unfamiliar authorized advisor must check all gold answers and complete source packets, approve reuse, record hashes/retrieval dates and freeze the revision. Gold answers and implementation were authored by the same AI-assisted process; no independence is claimed. Reserve three new matched cases held out from tuning. The original practice holdouts remain separate and are not evidence of real-source validation.

Randomize and counterbalance order across equivalent tasks; avoid reusing the same question immediately in both conditions. All participants receive equal vacancies, human advising, compensation and accommodations. Use only consenting adults and minimal pseudonymous data. See PILOT_OPERATIONS.md for consent, retention and rubric.

## Measures and denominators

Record condition/order, source-version hash, task start/end, actual intentional interactions, assistance, task fields, required/preferred/substitution judgments and unsupported claims. One click/selection/key command or committed field counts once; typing a field counts once. Do not estimate actions or time from an imagined flow. Two blinded raters independently score against the full source and reconcile disagreements. Report correctness as correct/all required judgments, evidence completeness as sourced fields/all expected fields, task completion as complete source-consistent tasks/all starters, and the five-item handoff rubric. Missing work stays visible. Report unsupported eligibility statements and missed mandatory conditions separately. Use medians/ranges for actual time/workload; no fabricated confidence or hiring causality.
