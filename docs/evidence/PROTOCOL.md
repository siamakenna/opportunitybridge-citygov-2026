# CCEB v1.0 — frozen internal protocol

Frozen before the first scored run. Twelve development and 48 evaluation IDs are in BENCHMARK_MANIFEST.json. Neither partition is independent: the AI-assisted developer author knows the implementation. All references await independent adjudication, n=0. No unseen external challenge set exists. Six retrieved official snapshots plus explicitly original synthetic fixtures/controlled perturbations are admitted. Unavailable/unreviewed sources are excluded as qualification references. The evaluation clock is synthetic, not a current availability claim. Publisher rights remain; URLs, short existing excerpts, paraphrases and digests are supplied, not full page archives.

Adapters receive only a cloned input, the same frozen source record and clock. No reference/rationale/ID enters a method. A uses normalized word boundaries, negation, simple published numerical thresholds, dates, document counts and exact pay wording. B uses explicit type metadata, minimal structured threshold formulas, review timestamps, dates and document counts. A/B deliberately do not implement the approved snapshot/receipt pipeline or Passport plan validation: those tasks are unsupported/N/A, never arbitrary zeros. Neither claims overall eligibility. C calls the actual production taxonomy, reviewRecord, lifecycle, catalogIssues, heldCatalog, mappingApproved, preparationStatus, validateJourney and connectionReview. C is not a second reference engine. Baseline parity is expected for simple tasks; differences need not favor C. No measured human baseline or manual time exists.

Primary reporting is by task and partition, not an aggregate across unlike decisions. Exact correctness compares the selected task's reference field (primary, deadlineStatus, missingDocuments or state). Unknown is an implemented abstention, not unsupported. Classification confusion matrix and each reference class precision/recall/F1 are reported; zero-denominator precision/recall is null and undefined F1 contributes zero to the fixed reference-label macro F1. State correctness, required abstention recall, incorrect abstention among definite references, unsupported affirmative answers, and overall eligibility assertions are distinct counts. A supported checklist or complete draft is not eligibility. Source-link equality is reported only for actual official-source cases without deliberately changed URLs; equality does not validate a live page. Document missing-count and exact-deadline correctness are separate. Plans use five binary criteria: source URL, valid target, proposed artifact, human question, retained uncertainty. This is a field/actionability proxy, not human usefulness or truthful employment verification. Missing facts are production unresolved selected conditions only; no invented universal denominator.

Binary proportions show numerator/denominator and nominal 95% Wilson bounds. Intervals are descriptive for this authored collection; dependent cases and pending references prevent population/generalization claims. Prespecified C−A/C−B exact-correctness differences use only common implemented cases within each task and partition, seeded 20261027, 5000 paired cluster bootstrap draws. Cluster is official source ID or synthetic fixture family (all synthetic classifier cases one family). Fewer than two source/family clusters yields N/A. Few clusters yield unstable intervals and no significance claim. Repeated executions test determinism, not additional samples. Exclusions are unsupported tasks only, listed in outputs; no failed case deletion or reference revision after scoring.

Twenty named red-team scenarios reuse distinct cases; they are not twenty extra independent samples. Every discrepancy is retained with source, input, actual and authored expected output. Repairs after results are developer-directed retests of known cases; retain before/after and do not relabel as blind evaluation. Critical source/receipt authorization failures block publication. Conservative abstention, descriptive classification gaps and limited claim-screen misses require explicit limitations; no claim of comprehensive semantic verification. Unknown full eligibility must survive every interaction.

Independent reviewers work separately with the source-only packet; raw decisions are append-only, disagreement retained, third adjudicator reconciles with rationale. Agreement is pending until real independent rows exist. No external registration is claimed by this local, Git-frozen protocol.

Reproduce: `node scripts/cceb-run.mjs --out output/evidence-v09/run-1.json`, repeat to run-2.json, then `node scripts/cceb-report.mjs`. Requires Node 18+ and repository only; no credentials or network. Do not rerun cceb-author.mjs after freeze: it is an audit trail of construction, not a scoring prerequisite.
