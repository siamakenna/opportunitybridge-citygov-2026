Verify current official source state before recording and keep that state visible. Use the existing screenshot sequence only with its actual capture date and format label.

“A student knows introductory HTML, but an unfamiliar public-service job description does not explain what they should prepare. OpportunityBridge helps them connect classroom work to an employer duty and leave with three next actions for an advisor.”

Show the main entry and launch the complete example.

“Here is the official employer source and the reviewed duty. Here is the fictional learner's coursework. The app proposes a work sample and keeps qualification questions visible. This source needs a current check before the learner invests time in preparation.”

Inspect the actual source status. If the source is currently fresh or closed, replace the final sentence with the observed behavior. Show the skill, duty, proposed work and unknowns.

Download and open the actual plan. Show source/date, three actions and one question. Do not display private files.

Both routes were verified locally; show the second route in that local preview. If unavailable, demonstrate a different supported skill within the verified route and state the actual coverage limit.
